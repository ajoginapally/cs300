cs300-java

This folder contains organized Java examples and reference files for CS300 (UW–Madison) topics and prerequisite knowledge.

Structure:
- prerequisites/: basic Java syntax, control flow, and simple examples
- topics/: data structures, algorithms, complexity, and advanced topics

Each Java file contains multiple small methods illustrating subtopics; feel free to split further into separate files or packages as needed.

To compile and run an example:

javac topics/Arrays.java && java topics.Arrays

Or run any file's `main` method similarly.
